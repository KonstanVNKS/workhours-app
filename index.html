    Data

    Your shifts are saved only on this device, in this browser. Nobody else can see them. On iPhone, add the app to your Home Screen so Safari doesn't clear the data, and export a CSV now and then as a backup.

    Import a CSV with columns: date, start, end, break minutes, rate, note. Only date, start and end are required; ',' or ';' separators both work. Shifts that already exist are skipped. Files exported from the Android app work here too.

    Shyfter

    Shyfter's API only accepts keys created by an account admin, so automatic sync isn't available with a regular employee login. Use Clock in / Clock out here alongside Shyfter, or import a CSV export of your clockings.
